# 題目描述
給一個字典，字典裡總共 $N$ 個單字，每個單字長度不超過 50，接著詢問 $Q$ 次，對於每一組詢問 $S$，輸出字典裡有多少個<br>單字存在 $S \in $ Word<sub>i</sub>$.substring()$。
# 輸入格式
輸入一行會有一個整數 $N$，表示接下來字典裡的 $N$ 個單字，接著會有 $N$ 行表示字典單字，接著會有一行一個整數 $Q$，表<br>示接下來有 $Q$ 組詢問，每一組詢問一行 $S$
- $N$ &leq; $200$
- $Q$ &leq; $50$
# 輸出格式
對於每一組詢問，輸出有多少單詞存在子字串恰好為 $S$。
# 範例輸入
```
4
moemoeta
stephen
yoooo
phew
4
moe
o
ph
oo
```
# 範例輸出
```
1
2
2
1
```
