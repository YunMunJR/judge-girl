# Task Description
寫一個程式來解決一下問題。<br>
有雞、兔子和螃蟹在同一個籠子裡。 現給定這些動物的總數 $(s)$、動物腳的總數 $(f)$ 及動物尾巴的總數 $(t)$，<br>$(0≤s,f,t≤2^{31}−1)$  請計算雞、兔子、螃蟹的數量。<br>
給定的數字保證有解。
# Sample input
```
9 48 5
```
# Sample output
```
2
3
4
```
